# Multi-Objective Shell-and-Tube Heat Exchanger Optimization Framework

Python implementation for automated sizing, Pareto multi-objective optimization (Area vs. Pressure Drop), and knee-point selection of shell-and-tube heat exchangers using TEMA standards.

## Features
- **TEMA Regulations:** Enforces geometric aspect ratios, standard baffle pitch ratios, and tube counts.
- **Thermal & Hydraulic Rating:** Gnielinski, Bell-Delaware, Sieder-Tate, and Hausen correlations.
- **Multi-Objective Pareto Analysis:** Automated Knee-Point detection for optimal thermal area and hydraulic pressure drop trade-offs.
- **Cross-Validated:** Benchmarked against ASPEN Exchanger Design & Rating (EDR).
